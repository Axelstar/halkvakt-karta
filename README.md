# Halkvakt-karta

Live-karta över svenska väglag: halka, vägväder, olyckor och fartkameror.
Data hämtas från Trafikverkets öppna API och uppdateras var 30:e minut av
en automatisk pipeline. `data/` skrivs av en bot — redigera inte för hand.

Datakällor: Trafikverket (CC0). Baskarta: OpenFreeMap © OpenStreetMap-bidragsgivare.
