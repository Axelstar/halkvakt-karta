Kärnlöftet: din position lämnar aldrig telefonen. All matchning mellan var du är och vad som finns på vägen sker lokalt i appen.

// Vad vi samlar in

Ingenting. Halkvakt har inga konton, ingen inloggning, ingen annonsering, inga analys- eller spårningsverktyg från tredje part, och skickar aldrig din position, dina resor eller något annat om dig till oss eller någon annan.

// Hur appen ändå fungerar

  • Appen hämtar ett paket med aktuella vägfaror (halka, olyckor, vilt, frysrisk, fartkameror) från vår server. Hämtningen är anonym — inget om dig eller din plats skickas med.
  • Jämförelsen mellan din position och farorna görs helt i din telefon. Resultatet läses upp med telefonens egen röst.
  • Varningshistoriken du ser i appen sparas endast lokalt på din enhet och försvinner om du avinstallerar appen.

// Behörigheter appen ber om

  • Plats (även i bakgrunden): för att veta vad som finns på vägen framför dig medan du kör med släckt skärm. Används enbart lokalt.
  • Fysisk aktivitet: så att vakten kan starta sig själv när du börjar köra.
  • Bluetooth: för att känna igen bilens ljudsystem och tala i rätt högtalare.
  • Notiser: för förgrundstjänstens statusnotis och varningar.

// Teknisk nödvändighet

När appen hämtar vägdata sker vanlig internettrafik — din IP-adress passerar då, som vid all webbtrafik, våra leverantörers standardloggar (GitHub Pages respektive Supabase). Vi läser inte, sparar inte och kopplar aldrig sådana loggar till någon person.

// Datakällor

Vägdatat kommer från Trafikverkets öppna data (CC0), Polisens viltolycksrapporter och SMHI:s vädervarningar. Det är data om vägar och väder — aldrig om dig.

// Ändringar & kontakt

Ändras policyn uppdateras denna sida och datumet ovan. Frågor? Kontaktuppgifter publiceras i samband med att halkvakt.se öppnar; fram till dess når du oss via förregistreringen på startsidan.
